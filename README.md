# Memory Game

Windows Forms ilə hazırlanmış 8 kartlıq yaddaş oyunu.

## Oyun qaydası
- 8 kartın arxasında 4 fərqli rəng var; hər rəngdən 2 ədəd yerləşdirilir.
- Eyni rəngli iki kart açıldıqda düzgün addım sayı 1 artır və kartlar açıq qalır.
- Rənglər fərqli olduqda səhv addım sayı 1 artır. Xal/düzgün addım sayı dəyişmir və kartlar qısa müddət sonra bağlanır.
- Bütün 4 cüt tapıldıqda oyun başa çatır.
- **Yeni oyun** kartları yenidən qarışdırır, **Çıxış** proqramı bağlayır.

## Açmaq
1. `MemoryGame.sln` faylını Visual Studio 2022 ilə açın.
2. .NET 8 SDK və Windows Forms dəstəyi quraşdırılmış olmalıdır.
3. `F5` düyməsi ilə başladın.

Layihədə əlavə NuGet paketi tələb olunmur.
